## Objetivo general
Analizar la evolución y la correlación entre las emisiones de gases de efecto invernadero y la temperatura promedio nacional, así como entre las precipitaciones y la pérdida de cobertura arbórea, en Costa Rica durante el periodo 2001-2024, mediante estadística descriptiva y visualización de datos.


## Estructura del proyecto
- `cod/`: Scripts de análisis y documentos .qmd
- `data/`: Datos de entrada (crudos) y editados en excel.
- `info/`: Documentación, enunciado, referencias y minutas.
- `config/`: Parámetros, rutas y configuraciones de ejemplo.
- `res/`: Resultados generados por el código (tablas, gráficos, reportes).
